Privacy policy

Last updated: 7 October 2026

Inbox Cleaner is a personal tool used only by its owner, on the owner's own Gmail account. It has no other users.

Data the app accesses

With the owner's permission, the app reads the owner's Gmail messages (sender, subject, labels, headers and message text), changes labels, archives messages, moves messages to the trash, and sends unsubscribe requests on the owner's behalf.

How the data is used

Gmail data is used only to show the owner their own mail, sort it into categories, and carry out the clean-up actions the owner chooses. It is not used for advertising and is not used to train generalised machine learning models.

Where the data is stored

Gmail data and the sign-in token are stored only on computers the owner controls. There is no hosted service and no shared database.

Sharing

Gmail data is not sold and is not shared with third parties, except where the owner sets up a service to process their own mail on their behalf.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete all stored data by deleting the app's data folder.

Contact

Questions can be raised as an issue on this site's GitHub repository.
